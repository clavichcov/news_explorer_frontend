# News Explorer - Frontend

Aplicación React para buscar y guardar noticias de todo el mundo.

## 🚀 Características

- 🔍 Búsqueda de noticias en tiempo real usando NewsAPI
- 📰 Visualización de artículos en tarjetas responsivas
- 🔐 Autenticación de usuarios (registro/login)
- 💾 Guardar artículos favoritos
- 🗑️ Eliminar artículos guardados desde la vista de inicio o guardados
- 📱 Diseño responsive para algunos dispositivos
- 🎨 Iconos dinámicos según estado de autenticación y guardado
- ⏳ Preloader y carga progresiva de artículos (carga más)
- 🛡️ Rutas protegidas para usuarios autenticados
- ✨ Validación de formularios en tiempo real

## 🛠️ Tecnologías

- **React 18** - Biblioteca principal
- **Vite** - Bundler y dev server
- **React Router DOM v6** - Navegación entre páginas y rutas protegidas
- **Context API** - Manejo de estado global:
  - 👤 Usuario (autenticación, datos del usuario)
  - 🔍 Búsqueda (query, keywords, resultados)
  - 📰 Artículos (cards de búsqueda, artículos guardados)
- **CSS Modules** - Estilos modularizados y BEM naming
- **ESLint** - Linting y calidad de código
- **NewsAPI** - API externa para obtener noticias actualizadas
